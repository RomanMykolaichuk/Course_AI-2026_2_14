# Data Sources

This document is the registry for all external datasets used by the project.

## Source acceptance checklist

Before adding a source, record:

- source name;
- publisher/maintainer;
- public URL;
- access method (CSV, JSON, API, HTML, manual export);
- historical coverage;
- update frequency;
- geographic granularity;
- available event fields;
- license / terms of use;
- known gaps or biases;
- date when the source was checked.

## Selection criteria

Priority is given to sources that are:
1. openly accessible;
2. historically consistent;
3. sufficiently documented;
4. machine-readable;
5. suitable for reproducible academic/educational use.

No source should be ingested into the project before its provenance and limitations are documented here.
